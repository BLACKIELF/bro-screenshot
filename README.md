# bro截图

macOS 微信截图习惯替代工具：退出微信后，不登录微信也能继续用熟悉的 **⌘⌃A（Command + Control + A）** 截图。支持截图标注、复制、保存、Apple Vision 本机文字识别和 macOS 本机翻译，并与微信启动/退出联动。

![bro截图图标](work/assets/app-icon-1001v1.png)

公开版本：**1.0**。当前源码为 **1002v4 · build 20261002.4**，已在本机更新应用。仓库提供源码和构建脚本，不包含预编译 app 或腾讯二进制组件。`v1.0` 标签保留首次发布内容，后续优化见 `main`。

## 为什么做这个程序

我习惯用微信截图的 ⌘⌃A。退出微信之后，手还是会按同样的快捷键，但截图功能也跟着微信退出了。为了不用只为截图而登录微信，我写了 bro截图，让这个熟悉的操作继续可用。

微信退出时，bro截图接上同一个快捷键；微信启动时，bro截图退出，把快捷键交回微信。

**关键词：微信截图、微信退出后截图、不登录微信截图、macOS 截图、⌘⌃A、OCR、文字提取、本机翻译、截图原位翻译。**

## 环境

- Apple Silicon Mac，macOS 14.4 及以上；本机翻译需要 macOS 15 及以上。
- Xcode 及包含 Translation 框架的 macOS SDK。
- 本机已安装提供所需截图框架的 QQ。框架由构建脚本从本机读取，仓库不分发它们；组件接口不匹配时应用会拒绝启动截图编辑器。

## 构建

在仓库根目录运行，输出目录必须不存在：

```sh
# 纯源码编译/链接，不创建 app、不复制组件、不签名、不启动界面
bash work/compile-source.sh qa/source-check-1002v4

# 构建独立 app；从本机 QQ 读取组件，默认使用 ad-hoc 签名
bash work/build.sh candidates/local-1002v4
```

脚本会先切换到 `work/`，所以相对输出目录以 `work/` 为基准。完整 app 输出为 `work/candidates/local-1002v4/bro截图.app`，包含签名的 `BroOCRHelper`，需保留完整包。需要使用已有签名身份时，可设置 `TC_SIGN_IDENTITY`；不会创建证书或修改系统信任。

源码中使用部分腾讯组件的私有接口，并逐一核对完整 arm64 类型编码。组件版本变动可能导致兼容性校验失败；不能用关闭校验的方式继续截图。

## 启用微信联动

把构建出的 app 安装到 `/Applications/bro截图.app`，通过 macOS 正常授权录屏。仅标准安装路径允许注册联动服务；候选包不会注册服务。

联动使用公开的 `SMAppService` LaunchAgent API。系统若要求批准，通过“系统设置 → 通用 → 登录项”正常确认。后台代理负责监听微信并恢复主应用；微信运行时退出的是截图主进程和它的热键。

应用菜单可以开关联动。升级可执行文件时，需要通过应用的正常联动开关注销并重新注册服务；不会修改 TCC 数据或绕过系统批准。

安装包的只读检查：

```sh
'/Applications/bro截图.app/Contents/MacOS/TencentCapture' --verify-engine
'/Applications/bro截图.app/Contents/MacOS/TencentCapture' --lifecycle-status
```

这两个检查不创建 NSApplication 界面。接口校验通过不能代替真实录屏权限和截图验收。
