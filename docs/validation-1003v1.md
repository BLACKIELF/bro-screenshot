# 验证说明 · 1003v1

公开版本 1.0，build 20261003.1，2026-10-03。相较 1002v7，本版修复原位翻译辅助工具栏在截图编辑阶段遮挡选区的问题：工具栏在每个可用显示器上寻找同时避开当前选区和原生工具栏的位置；没有安全位置时隐藏面板。选区变化、原生工具栏移动/缩放/换屏都会重新计算，设置子窗口位置后还会复核 AppKit 实际 frame。

本机已执行：

- 严格源码编译/链接通过，包含 arm64 Objective-C、C 和 Swift 目标。
- 工具栏离屏几何断言 49,523 项通过；窗口/选区更新集成断言 20 项通过。全屏选区或没有安全空位时，辅助面板保持隐藏。
- 候选应用构建、完整签名和私有组件接口校验通过；应用与生命周期代理的启动/退出联动回执通过。

真实拖选、工具栏按钮点击、颜色弹窗和最终导出像素尚未完成桌面 GUI 验收，因此这些项目不标记为通过。公开仓库只同步源码、合成测试和说明，不分发腾讯组件、应用包、截图、运行日志或签名资料。

## 无 GUI 复跑

需要 Apple Silicon、macOS 14.4+、Xcode 和已正常安装的匹配组件。纯源码编译不需要启动界面或录屏权限：

```sh
export_test_dir=$(mktemp -d)
bash work/compile-source.sh "$export_test_dir/compile"
```

构建独立应用需要本机 QQ 提供的截图框架：

```sh
bash work/build.sh candidates/local-1003v1
```

输出目录必须不存在。脚本会验证框架签名、编译源代码、生成图标、签名应用并写入候选清单；不会启动界面、请求录屏权限或复制本机数据。

接口校验通过不能代替真实录屏权限和截图验收。其他实现和回归边界见 [1002v7](validation-1002v7.md)。
